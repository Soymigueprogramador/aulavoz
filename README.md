# AulaVoz

AulaVoz es una aplicación orientada a facilitar el acceso a material académico mediante la conversión automática de documentos PDF a audio.

## Tecnologías

### Frontend
- React
- Vite
- JavaScript

### Backend
- Python
- FastAPI

### Procesamiento
- PyMuPDF
- Text-to-Speech
